# Dulse-gfx-preset

## Overview

graphic resource preset of dulse.

* Pipeline
* Texture
* ShaderCode
* Shader's Uniform buffer structure

## Usage

dub.sdl
```SDL
dependency "dulse-gfx-preset" version=">=0.1.0"
```

dub.json
```JSON
"dependencies":{
	"dulse-gfx-preset":">=0.1.0"
}
```

import in D
```Dlang
import dulse_gfx_preset;
```
